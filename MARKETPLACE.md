## Custom HTTP gateway for PeltyCMS

Hosted checkout, webhooks, refunds and multi-currency capture as a sandboxed WASM payment gateway. Wire API keys in Pelty Admin → Payments, map products to gateways, and let clients pay invoices without custom PHP.

### Features
- Create + capture payments from Pelty invoices
- Signed webhook handling
- Sandboxed WASM (no host PHP)
- Works with Pelty tax, credit and multi-currency

### Requirements
- PeltyCMS with WASM addons enabled
- Valid Custom HTTP gateway API credentials
